🎮 Bot Detona Ralph com Playwright
📌 Sobre o Projeto
Este projeto nasceu durante um bootcamp da DIO, onde inicialmente desenvolvi um jogo de clicar inspirado no Detona Ralph.
Posteriormente, em um teste técnico em Java relacionado a web scraping, surgiu a oportunidade de aprofundar meus estudos na área. Durante essa pesquisa, descobri o Playwright, uma poderosa ferramenta que facilita automações e web scraping em JavaScript.
A partir daí, tive a ideia de criar um bot automatizado capaz de jogar o jogo do Detona Ralph sozinho, simulando cliques e interações na tela de forma inteligente.

🚀 Tecnologias Utilizadas
- JavaScript / Node.js → linguagem principal do projeto
- Playwright → automação de navegador e web scraping
- HTML / CSS → base do jogo desenvolvido no bootcamp
- GitHub → versionamento e compartilhamento do código
